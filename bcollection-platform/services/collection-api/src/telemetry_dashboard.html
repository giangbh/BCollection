Tích Hợp Sẵn Sàng Với Grafana & Prometheus

1. Cấu hình Prometheus Scraper (prometheus.yml)

File cấu hình đã được tạo sẵn tại deploy/telemetry/prometheus.yml:

scrape_configs:
  - job_name: 'bcollection-platform'
    scrape_interval: 5s
    static_configs:
      - targets: ['host.docker.internal:8088', 'host.docker.internal:8090']

2. Khởi chạy cụm Grafana bằng Docker Compose

Chỉ cần thực hiện 1 lệnh duy nhất tại thư mục dự án:

docker compose -f deploy/telemetry/docker-compose.telemetry.yml up -d

Sau đó truy cập Grafana tại http://localhost:3000 (User/Pass: admin / admin) để nạp Dashboard có sẵn.
